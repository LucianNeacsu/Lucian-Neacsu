# Agenți de social media pentru Cramele Odobești

Șase agenți specializați, fiecare cu regulile platformei lui. Toți citesc
aceeași fișă de brand — `brand/cramele-odobesti.md` — deci spun același lucru
despre cramă, indiferent cine îi întreabă.

## Cine ce face

| Agent | Pentru ce îl chemi |
|---|---|
| `strateg-social-vin` | plan de ansamblu, calendar pe toate canalele, buget, ce se filmează și când |
| `facebook-vin` | postări de Facebook, oferte, anunțuri, răspunsuri la comentarii |
| `instagram-vin` | Reels, carusele, postări de grid, Stories |
| `tiktok-vin` | scenarii video verticale, cu plan de filmare cadru cu cadru |
| `youtube-vin` | Shorts și filme lungi: tur de cramă, documentar de recoltă, educație |
| `linkedin-vin` | B2B — restaurante, distribuitori, retail, cadouri corporate |
| `conformitate-alcool` | verifică orice text **înainte** de publicare |

## Cum îi folosești

Îi chemi pe nume, în limbaj obișnuit:

```
Foloseste agentul facebook-vin ca sa scrii trei postari despre gama Monser.
```

```
Foloseste strateg-social-vin ca sa faci calendarul pe septembrie, stiind ca
in 12 septembrie incepe culesul.
```

```
Foloseste conformitate-alcool ca sa verifici textele din documentul de
Facebook inainte sa le public.
```

## Ordinea recomandată de lucru

1. **`strateg-social-vin`** — decide ce se face luna asta și ce se filmează.
2. **Agentul de platformă** — scrie materialul propriu-zis.
3. **`conformitate-alcool`** — verifică înainte de publicare. Acest pas nu se
   sare: o mențiune de sănătate strecurată într-o postare poate însemna
   reclamă respinsă, clip eliminat sau amendă.

## Ce trebuie actualizat în timp

Fișa de brand `brand/cramele-odobesti.md` este singura sursă de adevăr. Când
se schimbă ceva — o gamă nouă, o certificare, o suprafață, datele de contact —
se modifică acolo, o singură dată, și toți agenții preiau schimbarea.

Locurile de completat marcate între paranteze drepte (`[LINK_COMANDĂ]`,
`[PREȚ]`, `[TELEFON]`) rămân intenționat necompletate: agenții nu inventă
prețuri, tiraje, recolte sau recenzii.
